4. Domain & DNS — Cloudflare

Die Domain fspure.net ist bei Cloudflare, Inc. (101 Townsend St, San Francisco, CA 94107, USA) registriert; DNS läuft über Cloudflare.

  • DNS only (graue Wolke): Cloudflare löst den Namen auf; der Seiteninhalt kommt von GitHub Pages. Es fallen vor allem DNS-Anfragen an.
  • Proxied (orange Wolke): der Verkehr kann über Cloudflare laufen (CDN/Proxy); dann verarbeitet Cloudflare zusätzliche Verbindungsdaten. Empfohlen für diese Projektseite ist DNS only, sofern kein spezieller Schutzbedarf besteht.

Privacy policy von Cloudflare: cloudflare.com/privacypolicy.
