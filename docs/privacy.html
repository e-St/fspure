What this site does (and doesn’t)

Pages are static HTML. We do not set cookies, run analytics, show ads, or offer accounts, forms, or newsletters. Nothing here is used for profiling or marketing.

Hosting (GitHub Pages)

The site is served by GitHub Pages (GitHub, Inc., USA). When you load a page, the host may process usual request data such as IP address, time, URL, and browser user-agent — as almost any web host does. See GitHub’s privacy statement.

Domain & DNS (Cloudflare)

The domain is registered with Cloudflare; DNS is served by Cloudflare. They mainly answer name lookups; the page itself comes from GitHub.

External links

Links to GitHub and other sites leave fspure.net. Those sites have their own policies. We do not embed social plugins or third-party trackers.
